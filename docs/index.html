Project Report

Single Cell Visualization Suite

An integrated dashboard for exploring single-cell RNA-seq data.

Author: Rajan Ranjeet Tidke Repo: single_cell_int_viz

01 Overview

Single-cell RNA sequencing profiles gene expression at the resolution of individual cells, revealing cell types, states, and transitions that bulk sequencing collapses into an average. The analysis workflow, however, is fragmented across tools: quality control, dimensionality reduction, clustering, and visualization each typically demand a different library, and static plots limit how much of that structure a researcher can actually explore.

This project began as a team submission: a Dash-based platform unifying preprocessing and interactive visualization in one Python codebase. This report documents a solo rebuild of that project, reconstructed file by file, tested against real data at each step, with design decisions made deliberately rather than inherited by default.

03 Problem

Existing single-cell tools are powerful but fragmented. Preprocessing, clustering, dimensionality reduction, and visualization typically live in separate tools, and researchers without a programming background are largely excluded from the more advanced parts of the workflow. Popular methods like t-SNE and UMAP can also fail to preserve density information accurately at scale, and static plots make it hard to interactively compare how different dimensionality reduction techniques represent the same underlying structure.

The goal of this project is a single interactive platform that removes the need to stitch these tools together manually, while making the comparison between reduction techniques a first-class feature rather than an afterthought.

04 Method

Preprocessing pipeline

Built on Scanpy. Cells are filtered on mitochondrial content (pct_counts_mt < 5) and gene detection (n_genes_by_counts < 2500, min_genes ≥ 200); genes present in fewer than 3 cells are dropped. Counts are normalized to 10,000 per cell and log-transformed, then reduced to the top 2,000 highly variable genes and scaled (max_value=10).

PCA (40 components) serves as the shared basis for downstream steps. Leiden clustering runs on a 10-neighbor graph. Six embeddings are computed from there: UMAP in 2D and 3D, t-SNE, TriMap, a diffusion map, and PHATE — each capturing a different tradeoff between preserving local versus global structure.

Visualization layer

Built with Dash and dash-bootstrap-components, rendering with Plotly. The app is structured as a multipage Dash application (app.py + pages/), with a landing page and a tabbed dashboard page. Environment management uses conda, with pinned dependencies in config/requirements.txt for reproducibility.

05 Dashboard

The rebuilt dashboard is organized into eleven tabs:

Design decision: every embedding tab uses one shared cluster-to-color map rather than a different Plotly palette per method. A cell's color is identical on the UMAP tab, the t-SNE tab, and the PHATE tab — making cross-embedding comparison an actual analytical tool rather than a visual coincidence.

06 Evaluation

Every callback in the rebuilt dashboard was individually exercised against the real processed dataset before being considered complete, not just visually inspected, but called directly and checked for correct trace counts, figure shapes, and absence of runtime errors. All ten interactive callbacks (six embeddings, QC metrics, PCA variance, gene expression overlay, and the marker heatmap) passed this check.

This differs from the original team submission's evaluation, which centered on a 10-participant user study measuring usability and runtime across the full ~100,000-cell dataset. That user study has not been repeated here; this rebuild's evaluation is limited to functional correctness against the smaller bundled subsample.

07 Limitations

  • Only supports unimodal scRNA-seq data in .h5ad (AnnData) format.
  • No multi-modal support (ATAC-seq, spatial transcriptomics, CITE-seq).
  • Preprocessing pipeline has not yet been independently re-verified against raw data by me (see Status).
  • Bundled dataset is a ~2,453-cell subsample, not the full ~100,000-cell dataset described in the original report.

08 Roadmap

  1. Re-run and verify single_cell_processing.py against raw data end-to-end.
  2. Add support for additional input formats (Seurat objects, Loom, CSV matrices).
  3. Explore multi-modal integration (ATAC-seq, spatial transcriptomics).
  4. Automated cell type annotation against public reference atlases.
  5. Exportable, publication-ready figure generation.
